Laboratorio MSAL 2.0

Inicia sesión con Microsoft Entra ID, obtén un access token y úsalo contra Microsoft Graph. Todo ocurre en el navegador: esta página no tiene servidor propio.

  1. Iniciar sesión

    Abre la ventana de Microsoft y devuelve una cuenta.

  2. Pedir el token

    MSAL lo entrega desde su caché o lo renueva si venció.

  3. Llamar a Graph

    Envía el token en el header Authorization.

  4. Cerrar sesión

    Limpia la caché de MSAL en esta pestaña.
